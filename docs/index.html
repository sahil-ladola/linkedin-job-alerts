LinkedIn Job Alerts

A personal, self-hosted n8n workflow.

LinkedIn Job Alerts is a small automation I built for my own job search. It runs on my own computer in a self-hosted n8n instance and has one user: me.

What it does

  • Once an hour it reads the job-alert emails LinkedIn sends to my own Gmail inbox.
  • It splits each email into one row per job: job id, title, company, location and a link.
  • It removes jobs it has already seen and writes the new ones to my own Google Sheet.
  • It sends the title, company and location of each new job to the Google Gemini API to sort it into a rough category.

Why it asks for Google access

The workflow signs in with Google so that it can read those alert emails in my Gmail account and write rows to my Google Sheet. It is not offered to other people as a service.
